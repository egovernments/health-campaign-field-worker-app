How to update this log

Whenever you commit a config-only JSON change under apps/health_campaign_field_worker_app/lib/sampleJsonConfigs/ (or an equivalent flow-config file), add a new row at the top of the table with:

  1. Date — ISO date of the commit.
  2. Commit — short SHA once committed, or unstaged while pending.
  3. Campaign — SMC, POLIO, SMC + POLIO, or GENERAL.
  4. File · Location — file name and the block / line range.
  5. What changed & the config — one-line summary plus a <pre class="config"> block showing the actual JSON. Use <span class="add">/<span class="del"> for diff-style coloring and <span class="hunk"> for section headers. Link back to any origin commit if the change is a restore.
